FamilyPay

Projeto de estudo desenvolvido em Java para simular um sistema de autorização de compras entre filhos e responsáveis.

Sobre o projeto

O FamilyPay tem como objetivo representar uma situação em que um filho solicita uma compra e um responsável pode aprovar ou rejeitar essa solicitação.

O projeto foi desenvolvido como uma forma de praticar conceitos fundamentais de programação orientada a objetos em Java.

Funcionalidades atuais
Cadastro de filho com nome e número da conta;
Solicitação de compras;
Validação de valores inválidos;
Controle do status da solicitação;
Aprovação de compras pelo responsável;
Rejeição de compras pelo responsável;
Impedimento de alteração de uma solicitação que já foi aprovada ou rejeitada.
